# Datasets — Generated & Versioned

This directory holds generated datasets used for testing and validation.
All datasets in Aegis MOS are self-generated by the simulator, not externally sourced.

## Contents (populated during build phases)

| Dataset | Phase | Purpose |
|---------|-------|---------|
| `cubesat_params.json` | 1 | Reference CubeSat subsystem parameters |
| `fault_signatures/` | 2 | Fault type signature library for correlation engine |
| `regression_scenarios/` | 3 | Scripted fault scenarios for regression testing |
| `audit_fixtures/` | 5 | Synthetic audit ledger test data |
